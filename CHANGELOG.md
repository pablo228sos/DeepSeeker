# Changelog

All notable repository releases are documented here.

## 1.0.1 - 2026-09-25

- Added original high-resolution field photographs of the completed vehicle.
- Added the recovered bill of materials and explicit record of missing hardware specifications.
- Added firmware compilation CI for the main controller, field mode, and camera controller.
- Added GitHub issue forms, pull-request guidance, ownership, security policy, and code of conduct.
- Added a machine-readable Apache-2.0 software license while retaining CC BY 4.0 for original data and documentation.
- Expanded the README with mission goals, headline results, archive completeness, and a complete quick start.

## 1.0.0 - 2026-07-18

- Preserved final main ESP32 and ESP32-S3 camera firmware.
- Preserved recovered M0014 and M0016 raw mission archives through Git LFS.
- Added synchronized telemetry, OpenDroneMap-compatible geolocation files, derived diagnostics, and reconstruction results.
- Added the final DeepSeeker paper, CAD files, planning tools, development history, reproducible telemetry analysis, and tests.
