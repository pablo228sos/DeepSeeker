# DeepSeeker

[English](README.md) | [Русский](README.ru.md)

**Автономный катамаран для синхронизированной съемки мелководья и движения по заданной зоне на озере Иссык-Куль.**

![DeepSeeker во время полевого испытания](docs/assets/field/deepseeker-side-profile.jpg)

DeepSeeker - недорогая роботизированная платформа для съемки дна, привязки подводных фотографий к координатам и последующей сборки связного визуального материала. Мы спроектировали, собрали, запрограммировали и испытали систему во время Young Scientists Camp 2026 на озере Иссык-Куль.

Репозиторий сохраняет восстановленную инженерную историю проекта: финальные и промежуточные прошивки, сырые архивы миссий, телеметрию, попытки реконструкции, успешные результаты, модели креплений, инструменты планирования и итоговую исследовательскую работу. Неудачные испытания оставлены рядом с успешной миссией, потому что именно они объясняют принятые решения.

## Главный результат

Миссия **M0016** сохранила 208 из 208 ожидаемых подводных кадров вместе с GNSS- и IMU-данными. Проход длился 279 секунд, медианная скорость составила 0,262 м/с, медианное время сохранения кадра - 445,5 мс. Обычно приемник видел 5-6 спутников; медианный HDOP составил 1,56.

![Маршрут и качество кадров M0016](docs/assets/M0016_track_and_quality.png)

Из прохода туда и обратно удалось собрать связную визуальную реконструкцию исследованной полосы дна.

![Экспериментальная мозаика M0016](docs/assets/M0016_research_result_figure.png)

Это экспериментальная полосовая мозаика, а не метрически подтвержденный ортофотоплан. Камера не была откалибрована под водой в установленном корпусе, расстояние до дна не измерялось, а обычный GNSS не обеспечивал геодезическую точность.

## Что находится в репозитории

- [`firmware/`](firmware/) - прошивки основного ESP32, ESP32-S3-CAM и история разработки.
- [`data/`](data/) - сырые миссии M0014 и M0016, телеметрия, `geo.txt` и результаты обработки.
- [`analysis/`](analysis/) - воспроизводимые расчеты и диагностические графики.
- [`docs/`](docs/) - архитектура, оборудование, навигация, полевые процедуры, результаты и ограничения.
- [`hardware/`](hardware/) - CAD-модели креплений сонара.
- [`tools/`](tools/) - планировщик AquaRoute и прототип наземной станции DRSKHUB.
- [`research/`](research/) - финальная 21-страничная исследовательская работа.

## Сохранность архива

Обе сырые миссии, телеметрия, геопривязка, финальные прошивки и производные результаты сохранены. Физическая microSD после лагеря была потеряна, а одноразовый исходный скрипт feature-aligned реконструкции восстановить не удалось. Мы не выдаем сохранившийся результат за полностью воспроизводимый: точная граница описана в [`docs/reproducibility.md`](docs/reproducibility.md).

## Быстрый старт

```bash
git lfs install
git clone https://github.com/pablo228sos/DeepSeeker.git
cd DeepSeeker
python -m pip install -r analysis/requirements.txt
python analysis/deepseeker_analysis.py summarize data/M0016/source/telemetry.csv
```

Перед повторным использованием стоит прочитать [`docs/results.md`](docs/results.md), [`docs/limitations.md`](docs/limitations.md), [`docs/field-operations.md`](docs/field-operations.md) и [`docs/bill-of-materials.md`](docs/bill-of-materials.md).
