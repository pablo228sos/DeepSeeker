# DeepSeeker

DeepSeeker - автономный катамаран для съемки мелководья, привязки подводных фотографий к координатам и движения по заданной зоне. Мы собрали и испытали систему на озере Иссык-Куль во время Young Scientists Camp 2026.

В этом репозитории сохранена вся работа: финальные прошивки, промежуточные версии, сырые полевые данные, телеметрия, попытки построения мозаики, удачные результаты, модели креплений и итоговая исследовательская работа.

Главный результат - миссия **M0016**. За 279 секунд камера сохранила 208 из 208 ожидаемых кадров вместе с GPS- и IMU-данными. Из прохода туда и обратно удалось собрать связную визуальную карту исследованного коридора дна.

Важно: это экспериментальная полоса-мозаика, а не геодезически точный ортофотоплан. Мы не измеряли высоту камеры над дном, не выполняли подводную калибровку объектива, а обычный GPS не дает сантиметровой точности.
