# Mission M0016

M0016 is the strongest recovered field mission. It contains 208 geotagged images from one outbound-and-return transect and no missing expected capture.

The derived products include two related experiments:

- A quality-selected pushbroom-style strip that combines outbound and return observations.
- A feature-aligned connected reconstruction made from sequential image registration.

Both products represent a narrow underwater corridor. Neither is a complete or metrically validated area orthophoto.

See [`derived/M0016_research_results.md`](derived/M0016_research_results.md) and [`derived/M0016_feature_aligned_map_notes.txt`](derived/M0016_feature_aligned_map_notes.txt).
