# AquaRoute Mission Planner v1.0

Первая браузерная версия редактора маршрутов для автономного катамарана на ESP32.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для загрузки карты нужен интернет.
4. Кликайте по карте для добавления контрольных точек.
5. Перетаскивайте маркеры для исправления маршрута.
6. Правый клик по маркеру удаляет его.
7. Нажмите `Скачать mission.json`.

## Что находится в mission.json

- название миссии;
- скорость;
- радиус достижения точки;
- HOME;
- исходные контрольные точки;
- автоматически созданные промежуточные точки для ESP32.

## Важное ограничение

Это планировщик маршрута. Он еще не отправляет файл прямо на ESP32. Следующий модуль — веб-панель ESP32 для загрузки `mission.json`, сохранения в LittleFS и запуска миссии.
