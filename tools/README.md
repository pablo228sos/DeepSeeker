# Planning and ground-station tools

## AquaRoute Mission Planner

The browser-based AquaRoute prototype allows a route to be drawn and exported as JSON. It is preserved as a planning experiment. It was not directly integrated with the final ESP32 upload path.

Open `AquaRoute_Mission_Planner/index.html` in a browser to inspect it.

## DRSKHUB

DRSKHUB is a PyQt6/MAVLink ground-station prototype with map, mission, telemetry, parameter, simulation, and fleet panels. It predates the final lightweight ESP32 workflow and is included as a separate software experiment. The local virtual environment has been excluded.
